# Experiment log

Append one row per evaluation run to `experiment-log.csv`. Keep local training-task results separate from Kaggle public scores. Never fill in an unknown score from a notebook title or a one-off claim.

Track the exact model, fixed task set, call/time budget, prompt/config hash, run environment, resolved count, failures, and source of the score. Store detailed traces under ignored `evals/results/<run-id>/` and summarize only the findings that change the next experiment.
